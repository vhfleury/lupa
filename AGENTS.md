# Lupa — instruções para agentes

As regras do projeto ficam em [CLAUDE.md](CLAUDE.md) e valem integralmente aqui. Leia esse
arquivo inteiro antes de qualquer tarefa; ele prevalece sobre este.

- Skills: `.agents/skills/`. Agentes: `.codex/agents/`. Os dois são cópias de `.claude/skills/` e
  `.claude/agents/`, que são a fonte; altere a fonte e gere as cópias de novo.
- Onde o texto citar ferramentas do Claude Code (`Skill`, `Agent`, `Read`, `Edit`, `Bash`), use a
  equivalente do Codex: a skill de mesmo nome, o subagente de mesmo nome, leitura, edição e shell.
